# StatMuse Builder

Build an NBA player-stat question ("Jayson Tatum points in the 4th quarter vs
Lakers in wins") and open it on [StatMuse](https://www.statmuse.com).

Live: https://statmuse-builder.vercel.app

```bash
npm install
npm run dev     # http://localhost:5190
npm run check   # lint + typecheck + unit + e2e
```

See [PROJECT.md](PROJECT.md) for status and design notes.
